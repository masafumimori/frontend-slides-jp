    第2章 二次関数§5

    定義域があるときは、
    軸の位置で最大・最小が決まる

    頂点がいつも答えになるとは限らない。軸が定義域の中か外かを見て、頂点と両端のyの値を比べる。

    用語
    定義域
    xのとりうる値の範囲。
    軸
    放物線の対称軸。y = a(x − p)2 + qなら直線x = p。
    端点
    定義域の両端。値を必ず計算する。
    基本事項下に凸（a > 0）のグラフと定義域の位置
    軸が定義域の左の外
    最小 左端　最大 右端
    軸が定義域の中
    最小 頂点　最大 軸から遠い端
    軸が定義域の右の外
    最小 右端　最大 左端
    上に凸（a < 0）では、最大と最小が入れかわる。色の帯が定義域。
    指針

    解答の左の見出しが、考える順番。平方完成 → 軸の位置 → 両端の値 → 比べる。

    よくある間違い

    頂点のy座標をそのまま最大値や最小値にする。頂点が定義域に入っているかを先に確かめる。

    例題1軸が定義域の中にあるとき重要度

    関数 y = x2 − 4x + 1（0 ≦ x ≦ 5）の最大値と最小値を求めよ。また、そのときのxの値を求めよ。

    平方完成y = (x − 2)2 − 3　頂点 (2, −3)、軸 x = 2
    軸の位置下に凸で、軸x = 2は定義域の中。頂点で最小になる。
    両端の値x = 0のときy = 1、x = 5のときy = 6
    比べる軸からの距離は 左端2・右端3。遠い右端で最大。
    答x = 5 で最大値 6、x = 2 で最小値 −3
    図1　帯が定義域。実線の部分だけが答えの候補。
    例題2軸が定義域の外にあるとき空欄 アイ を埋める

    関数 y = −x2 + 2x + 3（−2 ≦ x ≦ 0）の最大値と最小値を求めよ。

    平方完成y =ア−(x − 1)2 + 4
    軸の位置上に凸で、軸は定義域の右の外。定義域ではxが増えるとyも増える。
    両端の値x = −2のときy =イ−5、x = 0のときy = 3
    答x = 0 で最大値 3、x = −2 で最小値イ
    図2　アを埋めて頂点をかき入れてから開く。

    3つの場合を、自分で判定する

    解いてから［解答を見る］で確かめ、手ごたえを記録する。

    解き方の順番
    1. 平方完成して軸と頂点を出す
    2. 軸が定義域の中か外かを見る
    3. 頂点と両端の値を比べる
    練習1類題 → 例題1

    関数 y = x2 + 2x − 1（−3 ≦ x ≦ 1）の最大値と最小値を求めよ。

    計算

    y = (x + 1)2 − 2。軸x = −1は定義域の中。
    x = −3のときy = 2、x = 1のときy = 2（軸から等距離）。
    x = −3, 1 で最大値 2、x = −1 で最小値 −2

    手ごたえ
    指針

    軸から両端までの距離を比べる。距離が等しいとき、最大になるxはいくつあるか。

    練習2類題 → 例題2

    関数 y = 2x2 − 8x + 5（3 ≦ x ≦ 4）の最大値と最小値を求めよ。

    計算

    y = 2(x − 2)2 − 3。軸x = 2は定義域の左の外。
    x = 3のときy = −1、x = 4のときy = 5。
    x = 4 で最大値 5、x = 3 で最小値 −1

    手ごたえ
    よくある間違い

    2(x2 − 4x) + 5から平方完成するとき、−4に係数2を掛け忘れて2(x − 2)2 + 1とする。x = 0を代入して元の式と同じ値か確かめる。

    練習3類題 → 例題1・基本事項

    関数 y = −x2 + 6x（1 ≦ x ≦ 4）の最大値と最小値を求めよ。

    計算

    y = −(x − 3)2 + 9。上に凸で、軸x = 3は定義域の中。
    x = 1のときy = 5、x = 4のときy = 8。
    x = 3 で最大値 9、x = 1 で最小値 5

    手ごたえ
    指針

    上に凸なので、頂点が定義域の中なら頂点で最大。最小は軸から遠い端になる。
