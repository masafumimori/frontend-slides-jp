4-1血液の循環　心臓のつくりと血液の流れ

心臓は4つの部屋と弁で、
血液を一方向に送り出す

このページで分かること

  • 心臓の4つの部屋の名前と位置
  • 心臓の中を血液が流れる順番
  • 弁と、左心室の壁が厚いわけ
  1. 1大静脈 → 右心房全身をめぐった静脈血が、大静脈から右心房に入る。
  2. 2右心房 → 右心室血液は弁を通って、右心房から右心室へ流れこむ。
  3. 3右心室 → 肺動脈右心室が縮むと、血液は肺動脈へ押し出され肺へ。
  4. 4肺静脈 → 左心房肺で酸素を受け取った動脈血が、左心房に入る。
  5. 5左心房 → 左心室血液は弁を通って、左心房から左心室へ流れこむ。
  6. 6左心室 → 大動脈左心室が強く縮み、大動脈から全身へ送り出す。

まとめ

  • 心臓は右心房・右心室・左心房・左心室の4つの部屋に分かれる。
  • 心室が縮んで血液を送り出し、弁が逆流を防ぐ。
  • 全身へ送り出す左心室の壁がもっとも厚い。

4-2血液の循環　体循環と肺循環

血液は、肺循環と体循環の
2つの道すじをめぐる

このページで分かること

  • 肺循環と体循環の道すじ
  • 肺と全身で血液に起こること
  • 「動脈」と「動脈血」のちがい
  1. 1肺右心室 → 肺動脈 → 肺静脈血が、肺動脈を通って肺へ送られる。
  2. 2肺肺 → 肺静脈 → 左心房肺で二酸化炭素を出し酸素を受け取り、動脈血になる。
  3. 3体左心室 → 大動脈 → 全身動脈血が、大動脈から全身の毛細血管へ送られる。
  4. 4体全身 → 大静脈 → 右心房細胞に酸素をわたし二酸化炭素を受け取り、静脈血になる。
よくある
間違い

「動脈には動脈血が流れる」→ 肺動脈には静脈血、肺静脈には動脈血が流れる。

動脈・静脈
血管の名前。心臓から出ていく血管が動脈、もどる血管が静脈。
動脈血・静脈血
血液の名前。酸素が多い血液が動脈血、少ない血液が静脈血。

まとめ

  • 肺循環：右心室→肺動脈→肺→肺静脈→左心房
  • 体循環：左心室→大動脈→全身→大静脈→右心房
  • 血液は肺で酸素を受け取り、全身の細胞にわたす。
