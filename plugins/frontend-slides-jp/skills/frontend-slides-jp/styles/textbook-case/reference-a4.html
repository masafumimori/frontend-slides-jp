原価が6％上がった。
誰に、何から伝えるか

学ぶこと1値上げ幅を費用から説明する2タイプで順番と時期を変える3％を相手の言葉に直す

みなと製パン資材は、県内のパン店やホテルに小麦粉・バター・包材を卸す、社員42名の会社だ。年間売上は30億円、営業利益は0.9億円。利益率3.0％の薄い商売である。

この春、仕入先から値上げの通知が相次いだ。仕入原価は合わせて6％、委託している物流費も10％上がる。売値を据え置けば、営業利益は0.66億円の赤字に転じる（表1）。

営業部長の佐伯は電卓をたたいた。増える費用は1.56億円。売上30億円で割ると5.2％になる。平均5.2％の値上げなら、販売量が変わらない限り利益の額は守れる。

難しいのは顧客である（表2）。売上の4割を占めるスーパー内ベーカリー3社は、毎年相見積もりを取る。個人のパン店約180店は付き合いが長いが、店の利益も薄い。ホテル・カフェ40社は品質を重んじ、予算を年度で組む。

「全社一律5.2％で通知を出せば済みます」と言う若手に、佐伯は首を振った。「同じ5.2％でも、相手によって聞こえ方が違うんだ」

問1目安3分

全顧客に一律5.2％で通知してよいか。A・B・Cそれぞれに、何を・いつ伝えるかを考えよ。

まず自分で考える解説を見る前にメモする 3:00

解説 1

理由は全員に同じものを示し、伝え方と時期はタイプごとに変える。

A　最も早く
1社を失えば粗利で約0.8億円が消え、A全体から5.2％で得る0.62億円を上回る。仕入価格の推移を開示し、個別に交渉する。
B　訪ねて話す
担当者が訪ね、％ではなく月額で伝える（問2）。
C　予算の前に
次年度の予算が固まる前に通知し、品質を保つための値上げだと添える。

落とし穴　Aだけ3％に抑えると、残り1.20億円をB・Cの18億円で埋めることになり、B・Cは6.7％の値上げが要る。

討議28分

グループの結論（1文で）

講師用の論点討議2が終わってから開く

押さえる論点

譲る額は失う粗利と比べ、譲るなら条件と引き換えにする。

討議1
1社だけ3％にすると年880万円の減（4億円×2.2ポイント）。失えば粗利で約0.8億円。譲るなら発注量か契約期間を条件にする。差額をB・Cに回すとB・Cは5.69％になる。
討議2
B全体で半年待つと2,340万円の減（年0.468億円の半分）、1店では13万円。待つ店を絞り、発注のまとめ方で負担を下げる案を引き出す。
出やすい意見
「Bは据え置き」には、A・Cに7.4％が要るか、営業利益が0.43億円に下がることを計算させる。
