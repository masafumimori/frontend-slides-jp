調査日 2026-10-14。表記ルールは次のとおり。
- **[見た]** 内蔵ブラウザの Chrome PDF ビューアで実際に表示したページで確認した。
- **[推定]** 見たページから一般化したもの、または見ていないページについての推測。
- ページ番号は PDF のページ番号（p）。誌面に印刷されたノンブルとは1〜2ずれることがある。
- 解像度は低め（1ページ ≒ 横400px 程度）。本文書体の細部（ウェイト値、正確な pt）は [推定] になる。

前任エージェントのファイルは存在しなかったため、再利用したメモはない。全件を新規に見た。

## 調査方法と制約

- 各 PDF は新しいタブで `#page=N` を指定して開き、表示領域をスクショした。同じタブで別ページに移るとビューアが描画しなくなるため、1ページにつき1タブを使い捨てた。
- PDF・テンプレートのダウンロードはしていない。WebFetch で双葉の PDF テキスト抽出を試みた際、ツール側が自動で PDF を `~/.claude/projects/.../tool-results/webfetch-1791966486575-xqirq0.pdf` にキャッシュした。中身は読んでおらず、使ってもいない。他の PDF は 10MB 超で WebFetch が失敗した。
- 才流の縦型テンプレートは PPTX ダウンロードではなく、記事に埋め込まれた Speaker Deck プレーヤーで見た。

### 2-2. 縦型と 16:9 の違い

- **縦型は読ませる、横は見せる** [見た: 才流の記事] 縦型は文字数を増やせる。横型は投影・転用向き。縦では2段組の本文が成り立つ。16:9 では1枚1メッセージに戻す。
- **縦型は上から下へ積む** [見た] 「見出し → リード → 図 → 本文 → 注記」を縦に重ねる（中外 p20、大成 p62）。16:9 では「左に見出し、右に図」の横並びが自然になる [推定]。
- **ページの付属要素が多い** [見た] 縦型の冊子は章タブ（右端の縦タブ: 中外、大成、FR / 下端の横タブ: JLL）、柱付きのノンブル、英字キッカーで「今どこを読んでいるか」を示す。スライドでは章タブは要らず、小さなセクションラベルで足りる [推定]。
- **全面写真の使い方** [見た] 縦の全面写真は章扉に向く（FR、中外）。人物や建物の縦長構図が生きる。16:9 では横長の風景や群衆が向く [推定]。
- **横長が必要な情報は折り込みにする** [見た: FR p47] 地図、長いタイムライン、店舗数の推移は縦1ページに収まらない。FR は横長の折り込みで解決している。**HTML の A4縦文書では、該当するページだけ横向きのページ（`@page landscape` の名前付きページ、または見開き2ページ分の幅）を挟む**のが等価な手段になる [推定]。ただし印刷とPDF化の挙動は確認が必要 [推定]。
- **Web 閲覧が前提なら文字を大きく** [見た: 才流] 本文は A4 の印刷物より1〜2段階大きくする（本文 10.5〜11pt 相当以上）[推定: 数値は一般的な目安]。

## 3. スタイルファミリー（5つ）

### F1. 白地とブランド1色のコーポレート（Clean Corporate Blue）
- **特徴** 白地、ブランドの青または紺を1色、ゴシックのみ、英字キッカー＋和文の太い見出し、2段組、章タブ、薄い色の面で区分け。
- **実例** 中外 [見た]、JLL [見た]、大成 [見た]。
- **向く場面** 統合報告書、医療機器・製薬の企業案内、IR資料、BtoB の製品カタログ。
- **16:9 にも使えるか** 使える。中外の章扉（全面写真＋青いブロック）と KPI のシェブロンはそのままスライドになる [推定]。
- **AI が真似すると安っぽくなる点** 青から紫へのグラデーションを全面に敷く。角丸カードを均等に3列並べ、アイコンだけを変える。英字キッカーと和文見出しの大きさの差が小さい（実例では和文が英字の約3倍）。章タブやノンブルが無い。全ページで同じ青を同じ使い方にする（実例は章色や薄い色の面で変化を付けている）。

### F2. 写真主導のエディトリアル（Editorial Photo-led）
- **特徴** 全面の裁ち落とし写真、太いコンデンスの英大文字＋小さな和文、白・黒・ブランドの赤の3色、明朝の見出しで語りの声を出す、書や余白の多いページ、折り込みのインフォグラフィック。
- **実例** FR [見た]。中外の章扉も部分的にこれ [見た]。
- **向く場面** 消費者ブランド、トップの思想を伝える冊子、採用案内、ブランドブック。
- **16:9 にも使えるか** 強く使える（章扉、引用のスライド）。
- **AI が真似すると安っぽくなる点** フリー素材の「笑顔のビジネスパーソン」。写真の上に半透明の黒を一律に敷く。英字を太字のゴシックで代用する（実例は字幅の狭い専用書体）。明朝と英字のサンセリフを混ぜる理由が無い。写真の役割（服、人、店）が決まっていない。

### F3. 章ごとに色を変えるインデックス型（Color-coded Section System）
- **特徴** ブランドの色を骨格に、章ごとにアクセント色を変える（大成: 紺 / コーラル / ティール、双葉: オレンジ / 緑 / マルチ、JLL: 青 / 緑 / マゼンタ）。天罫や ■ 見出しの色が章色に変わる。表の行も色で分ける。
- **実例** 大成 [見た]、双葉 [見た]、JLL [見た]。
- **向く場面** 事業が複数ある会社の案内、製品ラインのカタログ、長い報告書。
- **16:9 にも使えるか** 使える。セクションの扉と小さなラベルの色で章を示す [推定]。
- **AI が真似すると安っぽくなる点** 章色を5色以上の彩度の高い色にする。色の意味（事業、章）の凡例が無い。章色を見出しにだけ使い、図や表に引き継がない。虹色のグラデーションを装飾に使う（大成は罫の端の1か所だけ）。

### F4. 親しみの物語型（Warm Narrative / Illustrated Story）
- **特徴** 暖色または淡い地（クリーム、薄い黄、薄い水色）、イラストやジオラマ、大きな番号 01〜07、吹き出しや問いかけ、口語のコピー（「ちゃんと考えて、ちゃんと実行する！」「Q. 企業風土改革に意見求む！」）。
- **実例** イオンモール [見た]、双葉の表紙と p3 [見た]、味の素の表紙のコピー [見た]、大成「Change」 [見た]、FR の人材ページ [見た]。
- **向く場面** サステナビリティ報告、採用、地域・生活者向けのパンフレット、患者・家族向けの説明。
- **16:9 にも使えるか** 部分的に使える。番号付きのストーリーと吹き出しは使える。ジオラマ写真は素材を作らないと再現できない [推定]。
- **AI が真似すると安っぽくなる点** 汎用のフラットイラスト（顔の無い人物、紫の肌）。どこにでもある人物素材。絵文字。吹き出しの中身が作文で、実在の声に見えない。番号が飾りになっていて、構成の骨格になっていない。

### F5. ホワイトペーパーの実務型（Practical Whitepaper）
- **特徴** 上下の固定帯（カテゴリーラベル＋タイトル / ロゴ＋CTA＋ノンブル）、紺と強調色の2色、番号付き見出し、円グラフと n 数、事例は「課題 → 効果」の帯、失敗例は ✕。
- **実例** 才流 [見た]。
- **向く場面** BtoB のリード獲得資料、製品の導入ガイド、調査レポート、医療従事者向けの資料。
- **16:9 にも使えるか** 使える。才流は横型テンプレートも公開している [見た: 記事本文]。
- **AI が真似すると安っぽくなる点** 帯が毎ページで微妙にずれる。プレースホルダー（〇〇、IMG）が残る。調査データに n 数と調査期間が無い。強調色を本文の半分に使う。CTA が無い。

（補足）統合報告書のデータ・ガバナンス部分は、どのファミリーでも「高密度の2段組＋細い罫線の表」に収束する [見た: JLL p60、中外 p70、味の素 p40]。ファミリーとは別の「データの付録」型として持つと扱いやすい [推定]。

## 4. 医療機器・ヘルスケア製品の冊子に使えるもの

- **骨格は F1（白地とブランド1色）＋F5（実務型）** [推定] JLL と中外は、医療業界の読者に向けた「信頼の文法」になっている。白地、青系の1色、ゴシック、細い罫、根拠となる数字 [見た]。
- **人体図から製品へ線を引く図** [見た: JLL p4] 半透明の人体に作用部位を示し、引き出し線で製品やモジュールにつなぐ。製品が体のどこに関わるかを示す図に置き換えられる [推定]。
- **作用と根拠を同心円や工程の図で** [見た: 中外 p12, p20] 機序の説明は同心円、臨床・開発の段階はシェブロン。どちらも装飾が少なく、数字が主役。
- **製品ページは双葉の型** [見た] 切り抜きの製品写真、■ 見出し、仕様の短い説明、使用シーンの写真。白い角丸カード（JLL）も医療機器の文脈で違和感が無い [見た]。
- **患者・家族向けの頁は F4 を控えめに** [推定] 線画イラスト（JLL「...for patient comfort.」）程度の温かさに留める。ジオラマや強い口語は医療機器では軽く見えるおそれがある [推定]。
- **注記・出典・n 数の欄を最初から設計に入れる** [見た: 中外の脚注、才流の n 数] [推定: 規制面] 医療機器の広告には薬機法と医療機器の適正広告基準による表現の制限があり、効能の表現と出典の示し方は法務確認が要る。デザイン側では脚注と注記の欄を最初から確保しておく。
- **アクセシビリティ** [見た: イオンの CUD 認証と音声コード] 高齢の利用者が想定されるなら、カラーユニバーサルデザインと大きめの本文は差別化にもなる [推定]。
- **避けること** [推定] 「青い泡、光の粒、分子のCG」のような抽象的な科学イメージを全面に敷く表紙。中外の表紙のような抽象 CG は、企業の思想を語る文脈だから成立している。製品の冊子では、製品の実物写真と使用シーンを優先する。
